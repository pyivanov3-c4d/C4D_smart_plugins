# 90° Rotate for Cinema 4D 2026

Select an object, activate **90° Rotate**, then drag an X/Y/Z ring with the left mouse button. No modifier key is required. Release to rotate exactly 90 degrees. The direction is inverted relative to the original version. Short drags do nothing; Escape cancels. Undo is supported.

The chosen ring turns yellow during the drag and returns to its normal color on release or cancellation. The toolbar icon shows a light-gray 90 on a transparent background.

Restart Cinema 4D after updating. The existing plugin folder and plugin ID are retained to preserve tool assignments.

The tool follows Cinema 4D's native World/Object coordinate-system toggle. In Object (local) mode the rings align with the active object's axes; in World mode they align with the world X/Y/Z axes. Dragging rotates around the displayed ring's axis. With multiple objects selected, the same chosen axis is applied to each selected root object around its own pivot.
